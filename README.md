# Rafter Cat's Chore List

A small to-do list for FFXIV (Dalamud plugin). Type your own chores, tick them off.

- One list shared by all your characters, plus one list for each character
- Opens when you log in (can be switched off)
- `/chores` or `/chorelist` opens and closes it

It doesn't read or change anything in the game, doesn't connect to the internet, and saves your lists on your own PC.

Install link (Dalamud > Settings > Experimental > Custom Plugin Repositories):
`https://raw.githubusercontent.com/The-Kinship/chore-list/main/repo.json`
